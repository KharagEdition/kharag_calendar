# Golden fixtures (generated from caltib)

These files are the accuracy contract of kharag_calendar: the Dart engines must
reproduce every value here exactly. They were generated by
`tool/golden/gen_golden.py` from the Python library
[caltib](https://github.com/gantemur/caltib) at commit
`bd15aa9031058fd7962de40e35421b9b6a21da40` (see `meta.json`).

| File | Rows | Content |
|---|---|---|
| `days_<trad>_1800_2200.csv.gz` | 146,462 each | `date,year,month,is_leap_month,tithi,occ,previous_tithi_skipped,linear_day` for every civil day 1800-01-01 .. 2200-12-31, from caltib `engine.day_info(date).tibetan` |
| `months_<trad>_1800_2200.csv.gz` | 4,986 each | `n,year,month,leap_state,first_jdn,last_jdn,tithi_end_jdns` for every lunation `n` from `first_lunation(1799)` to `first_lunation(2202)`; `tithi_end_jdns` holds the 30 values `civil_jdn(30n+1) .. civil_jdn(30n+30)` |
| `tables.csv.gz` | 8,352 | `table,phase,value_scaled`: moon table at every phase 0..3527 (value x 126) and sun table at every phase 0..4823 (value x 402) |
| `meta.json` | | caltib commit, command, range, row counts |

`<trad>` is one of `phugpa`, `bhutan`, `mongol`. Booleans are `0`/`1`.
`leap_state` is caltib's: `0` regular, `1` first of a duplicated month, `2` second.

## Regenerating

```sh
git clone https://github.com/gantemur/caltib /tmp/caltib
git -C /tmp/caltib checkout bd15aa9
python3 tool/golden/gen_golden.py --caltib-src /tmp/caltib/src --from 1800 --to 2200 --out test/golden
dart test test/golden_fixtures_test.dart
```

Python 3.9+ only; caltib's core has no third-party dependencies. Takes about a
minute. If caltib changes, regenerate from the new commit, update `meta.json`'s
commit in this README, and rerun the full `dart test` to see what moved.

The fixtures are excluded from the published package by `.pubignore`.
